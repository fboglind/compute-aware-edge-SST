# Development pilot

The four-configuration Pi pilot used the reserved recording `JhbtCwcsWY`, excluded from the six-talk main experiment. The pilot is discussed in the report. Its inference sources, input runs, reference extracts, evaluators, model preparation, scores and figure are retained.

Read `score-summary.json` and the saved `Pilot-quality-latency` figure for results. `plot_results.py` uses that summary and Matplotlib. `evaluate_pilot.py` and `score_pilot_grid.py` preserve the classical metric workflow; `score_comet.py` preserves neural scoring. These are experimental scripts, not notebook dependencies. Evaluation requirements and recorded environment versions remain beside them.

See the [code guide](../CODE_GUIDE.md) and [model preparation](../preparation/README.md).
