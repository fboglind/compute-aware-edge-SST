# Translation quality control

Open [TinyML_translation_QC.ipynb](TinyML_translation_QC.ipynb) for saved results offline. The Jev and detailed reviewer modules retain their prompts, schemas, thresholds and sampling logic. `recorded/` contains sample/window definitions, Jev decisions, summaries, final review outcomes, failed response examples and the original manual-inspection note. Full API invocation and attempt histories are in the separate supporting archive.

See the [code guide](../CODE_GUIDE.md) and [project README](../README.md).

Setup and fresh-run commands are in [REPRODUCE.md](../REPRODUCE.md).
